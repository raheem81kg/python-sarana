  }

┌──────────────────────────────────────────────────────────────────────────────┐
│  🌳 PARSE TREE EXAMPLE (for Report)                                         │
└──────────────────────────────────────────────────────────────────────────────┘

  Sarana Code:  bloom C = A + B * B;

  Parse Tree:
  └── Program
      └── BloomStatement "C"
          ├── name: "C"
          └── value:
              └── BinaryOp "+"              ← Root (evaluated LAST)
                  ├── Variable "A"
                  └── BinaryOp "*"          ← Nested (evaluated FIRST)
                      ├── Variable "B"
                      └── Variable "B"

  This shows PEMDAS:
    C = A + (B * B)
    C = 20 + (40 * 40)
    C = 20 + 1600
    C = 1620 ✓
